# 供应链需求预测：基线对比与误差分解

> Supply Chain Demand Forecasting — Baseline Comparison & Error Decomposition

基于 **412,020 条日粒度需求记录**（A/B 两条供应链、927 个「地理 × 商品」单元、近三年历史），
用四种预测方法做 98 天（14 周）需求预测，在等长回测集上择优，再把误差按 **预测步长 / 商品 / 单元规模** 三个维度拆开，
最后把误差折算成安全库存、与历史波动口径对照。回答三个问题：

**在没有算法团队、只有 Excel 和 pandas 的条件下，一个需求预测能做到多准？误差究竟出在哪里？这个误差，到底能不能换成更低的库存？**

> 第三个问题的答案是**不能**——而且能说清为什么不能。见第四节。

---

## 一、数据源

| 项目 | 说明 |
|---|---|
| 数据集 | 天池「供应链需求预测」（ID 均已脱敏） |
| 训练集 | A 组 284,832 行 / B 组 127,188 行 |
| 测试集 | A 组 61,936 行 / B 组 28,910 行（98 天 × 单元数） |
| 时间跨度 | 训练 2018-06-04 ~ 2021-03-01；测试 2021-03-02 ~ 2021-06-07 |
| 粒度 | 单元（地理节点 level3 × 商品节点 level2）× 日 |
| 规模 | A 组 632 个单元、81 个地理节点、19 个商品节点；B 组 295 个单元 |

| 文件 | 作用 |
|---|---|
| `use_train_X.csv` / `use_test_X.csv` | 需求主表（unit, ts, qty, 地理、商品层级） |
| `weight_X.csv` | 每个单元的业务权重，用于加权评估 |
| `geo_topo_X.csv` / `product_topo_X.csv` | 地理、商品的三层 / 两层拓扑 |
| `inventory_info_X.csv` | 2021-03-01 的单日库存快照 |

> 数据 ID 全部为哈希值，业务含义不可考，因此本项目只做**方法与精度**层面的分析，不对具体商品或地区下业务结论。

## 二、方法

```
数据画像 → 结构诊断（集中度 / 年度水平 / 周内效应）
    → 四种方法等长回测择优 → 全量重训预测测试集 → 误差三维分解
    → 误差折算安全库存 → 与历史波动口径对照
```

**预测方法**（每个单元输出一个预测值，均为常数预测）：

| 方法 | 说明 |
|---|---|
| 全历史均值 | 用全部历史数据平均，作为「不做任何时间加权」的对照 |
| 近 90 天均值 | 用最近一个季度的水平 |
| 近 28 天均值 | 用最近一个月的水平 |
| 指数平滑 α=0.1 | 对历史逐日做指数加权，近期数据权重更高 |

**为什么是常数预测？** 数据画像显示周内相对指数全部落在 0.999~1.001（见 `03_周内效应.csv`），
即需求不存在可用的周内规律；单元级需求近似平稳，因此常数预测是合理起点，也构成后续任何复杂模型的对照基线。

**回测设计**：训练集最后 98 天（2020-11-24 ~ 2021-03-01）作为验证集，与测试集跨度等长，
避免用「未来信息」选方法；选出加权 WAPE 最低的方法后，用全量训练集重新拟合。

**指标**：以 `weight_X.csv` 为权重的加权 WAPE（主指标）、加权 MAE、加权偏差（判断系统性高估/低估）。

## 三、主要结论

**1. 历史窗口比模型复杂度重要得多。**
全历史均值的加权 WAPE 为 16.05%（A）/ 20.21%（B），偏差 -13.2% / -18.6%——因为 2018 年日均需求是 2019 年的两倍
（A 组 10,700 → 5,476），把三年前的数据等权平均会系统性高估。换成近 28 天均值，WAPE 直接降到 3.70% / 6.53%。

**2. 最终精度：测试集加权 WAPE 3.85%（A）/ 4.04%（B），偏差 -1.2% / -2.0%。**
两组都由指数平滑 α=0.1 胜出，属于「略保守」的预测，符合备货场景偏好。

**3. 需求高度集中，但不是极端帕累托。**
A 组 16.1% 的单元（102 / 632）贡献 80% 需求，B 组为 14.6%（43 / 295）。
相对均衡的分布意味着**不能只盯头部单元**，尾部单元的服务水平同样影响整体体验。

**4. 误差的真正来源不是「平均不准」，而是「趋势跟不上」。**
- 按预测步长：第 1 周误差 1.1%~1.3%，第 14 周升到 6% 左右，误差随预测跨度单调放大 5 倍以上；
  同时偏差由正转负（A 组 +0.37% → -3.25%），说明测试期需求在缓慢上升，平滑法追不上。
- 按单元规模：大单元加权 WAPE 约 3.8%，小单元高达 27%~28% 且偏差 -22%~-23%，
  **低量单元的系统性低估是最大的一块结构性误差**。
- 按商品大类：占需求 57% 的主品类误差仅 3.1%，占 0.9% 的长尾品类误差 10.6% 且偏差 -7%。

## 四、预测驱动的安全库存：光有精度不够

前面的 WAPE 回答"能预测多准"，但不回答"所以该备多少货"。这一节把误差接进补货决策：
`SS = Z × σ × √L`，Z 按需求贡献分档（A 99% / B 95% / C 90%），关键变量是 **σ 该取哪个**。

同一批单元、同一个 L=7 天，三种 σ 口径各算一遍：

| σ 口径 | 含义 |
|---|---|
| σ全历史 | 训练集全程标准差，最常见的传统做法 |
| σ近98天 | 训练集最后 98 天标准差，窗口与预测跨度等长 |
| σ误差 | 测试期逐日残差标准差，即"预测实际没算准的那部分" |

**结果：**

| 组 | 全历史口径 | 对齐口径 | 误差口径 | 误差相对全历史 | 误差相对对齐 |
|---|---|---|---|---|---|
| A | 3,969,026 | 864,662 | 879,351 | **-77.8%** | **+1.7%** |
| B | 1,921,726 | 407,046 | 408,720 | **-78.7%** | **+0.4%** |

**两个结论，第二个更重要：**

**1.「用预测误差替代历史波动，能压缩近八成安全库存」是口径假象。**
全历史 σ 里混进了 2018→2021 的系统性水平下降（日均需求 10,700 → 5,476），把"趋势"记成了"预测的收益"。
把基准对齐到近 98 天，收益立刻消失——A 组 +1.7%、B 组 +0.4%，基本持平。

**2. 分规模看，低量单元反而要多备 40%~98%。**

| 规模档 | σ误差/σ近98天（A） | σ误差/σ近98天（B） | 安全库存变化（A） | 安全库存变化（B） |
|---|---|---|---|---|
| 小 | 1.41 | 1.61 | **+39.8%** | **+98.5%** |
| 中 | 1.24 | 1.21 | +39.2% | +64.1% |
| 大 | 0.92 | 1.05 | -4.0% | -6.6% |

低量单元的预测误差比原始波动还大——预测不但没减少不确定性，还额外引入了估计误差。
这与 `09_误差分解_规模.csv` 完全咬合：小单元 WAPE 27.9%，误差大 → 安全库存要备得更多，而不是更少。

**为什么是负结果：** 本项目四种方法全是**常数预测**。常数预测不解释任何波动结构，残差方差 ≈ 需求方差，
自然压不动安全库存。想靠预测降库存，前提是模型本身捕捉到了趋势/季节性——这正好指向第七节的改进方向。
换句话说，**预测的价值上限，由模型结构决定，而不是由 WAPE 数字决定**。

**稳健性**：SS ∝ √L，提前期取 7 / 14 / 30 天，误差口径相对对齐口径的偏差恒为 +1.7% / +0.4%，结论不依赖 L 的取值。

> 注 1：本节 ABC（按预测需求累计占比）与规模档（按日均需求三分位）基本是同一维度的两种切法——A 类全部落在"大"单元、C 类全部落在"小/中"，两者不宜当作独立解释变量。
>
> 注 2：`inventory_info` 未参与结论。其 qty 折算的覆盖天数中位数仅 0.073 天（A）/ 0.011 天（B），量级上不可能是可运营的库存水位，因此不做"库存缺口"测算。

## 七、局限

1. **只做常数预测** — 未建模趋势与节假日。这不只影响精度：第四节证明了常数预测的残差方差 ≈ 原始波动，
   因此**无法用来压缩安全库存**。
2. **单次回测** — 只用一个 98 天窗口选方法，方法排名对窗口选择有一定敏感性。
3. **α 未调优** — 指数平滑固定 α=0.1，未做网格搜索。
4. **库存快照量纲不匹配** — `inventory_info` 的 qty 均值仅 474，而单元日均需求为 6,680；折算出的覆盖天数
   中位数只有 0.073 天（A）/ 0.011 天（B），量级上不成立，因此**未做库存覆盖天数与缺口测算**，避免得出错误结论。
5. **提前期为假设值** — 数据未提供采购提前期，安全库存按 L=7 天计算，并用 7/14/30 天做敏感性。
   由于 SS ∝ √L，三口径的**相对**结论不受影响，但**绝对**库存量会随 L 变化。
6. **ID 已脱敏** — 所有地理、商品标识为哈希值，无法给出具名业务建议。

## 八、可拓展方向

- **引入趋势项**：对每个单元拟合近 56 天线性斜率并做衰减外推，或改为「每周滚动重估」，预计可显著改善后 6 周误差。
  更重要的是——若趋势项能把残差方差压到原始波动以下，第四节的负结论就会翻转，这才是"预测→补货"真正的价值前提。
- **分层建模**：低量单元单独处理（如借用同商品在邻近地理节点的需求形状做借力预测）。
- **按预测分布而非点预测做决策**：用区间预测的上下界确定服务水平，替代正态假设下的 Z 值。
